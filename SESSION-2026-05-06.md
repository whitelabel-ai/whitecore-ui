## Decisiones tomadas

- **[20:15] NextAuth.js v4 estable:** Descartamos v5 beta por peer dependency conflicts con Next.js 16. Usamos v4 con Credentials provider + JWT sessions.
- **[20:20] Scoring por severidad:** Fórmula = 100 - suma de penalizaciones. critical(-25), high(-15), medium(-8), low(-3). Floor en 0.
- **[20:25] Audit log automático:** `saveAreaContextAction` (Server Action) inserta audit row tras cada guardado. No dentro de `saveAreaContext` (dominio puro) sino en el adaptador.
- **[20:30] `saveAreaContext` retorna `areaContextId` + `action`:** Para facilitar el audit log sin necesidad de re-query.
- **[20:35] Middleware con `secret` explícito:** Edge runtime de Next.js 16 no siempre carga `.env.local`. Agregamos fallback en `middleware.ts`.

## Intentos fallidos

- **[20:17] Importar `NextAuth` desde `'next-auth'` en App Router:** Error de configuración (`error=Configuration`). Solución: importar desde `'next-auth/next'`.
- **[20:22] Query `getTimelineByCompany` con solo `ORDER BY created_at DESC`:** SQLite no garantiza orden entre filas con mismo timestamp. Solución: tiebreaker `id DESC`.

## Comportamientos inesperados

- **SQLite + foreign_keys en tests:** `auditAreaContextChange` fallaba con FK constraint porque los tests usaban `userId` ficticio. Solución: usar `userId` real del `registerCompany` result.
- **CDM cascada:** Actualizar `rules.md` disparó `BRAIN.md` porque `BRAIN.md` tiene `docs/rules.md` en `triggers_on`. Solución: actualizar ambos docs en secuencia.
- **Playwright EADDRINUSE:** Servidor de build previo quedaba en puerto 3000. Solución: matar procesos node antes de correr tests.

## Deuda técnica identificada

- **Sin asignación de áreas por rol:** En MVP cualquier usuario puede editar cualquier área. Post-MVP: asignar áreas específicas a usuarios.
- **Sin documentos adjuntos:** Solo texto en MVP. Post-MVP: subida de archivos/evidencia por área.
- **Sin notificaciones por email:** No hay alertas cuando alguien completa un área o hay problemas críticos.
- **Sin historial de versiones:** Audit log guarda quién editó y cuándo, pero no qué cambió exactamente (diff).
- **NextAuth v4 deprecated middleware:** Console warning sobre `middleware` → `proxy`. Post-MVP: migrar a `proxy` cuando Next.js lo estabilice.
